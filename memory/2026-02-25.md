## 🔍 Chrome 扩展问题记录（P2）

### 问题描述
- **端口**：
  - 18789（Gateway）：扩展连接后协议错误（"invalid request frame"）
  - 18792（Relay）：Token 认证失败（401 Unauthorized）

- **根本原因**：
  - Relay 的 WebSocket endpoint 不接受 Gateway token
  - HTTP endpoint 接受 token，但 WebSocket 拒绝
  - 可能是 OpenClaw 2026.2.22-2 的 bug

- **测试结果**：
  - HTTP: `curl -H "x-openclaw-relay-token: <token>" http://127.0.0.1:18792/` → 200 OK ✅
  - WebSocket: `ws://127.0.0.1:18792/extension?token=<token>` → 401 Unauthorized ❌

- **建议**：
  - 暂时不使用 Chrome 扩展
  - 可以在 GitHub 提 issue：https://github.com/openclaw/openclaw/issues
