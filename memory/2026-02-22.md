## 遇到的问题

### 1. 飞书连接失败
- **原因：** macOS 系统代理（Clash）的 SOCKS5 代理导致
- **错误：** `protocol mismatch: socks5h vs http`
- **解决：** 关闭系统代理
  ```bash
  networksetup -setwebproxystate Wi-Fi off
  networksetup -setsecurewebproxystate Wi-Fi off
  networksetup -setsocksfirewallproxystate Wi-Fi off
  ```

## 踩过的坑

### notebooklm login 需要交互式终端
- 不能远程按 ENTER
- 需要在本地终端窗口运行 `notebooklm login`
- 浏览器打开后看到 NotebookLM 主页，再按 ENTER

### NotebookLM rate limiting
- 一次性导入太多 URL 会被限制
- 524 个页面只成功导入了 50 个
- 建议：分批导入，每批间隔更长
