### 1. Claude Code 新功能 - Remote Control 🦞

宝玉分享的，Claude Code 出了个 `claude rc` 命令，可以生成链接/二维码，然后用手机或其他电脑远程控制本机的 Claude Code。

简单说：你在终端启动任务，出去散步或开会时可以用手机继续操作。

**我的看法**：
- 这个功能 OpenClaw 其实早就有了（Gateway + Node），不过 Claude 的实现更简单
- 但限制是：必须同一个 Claude 账号，安全性更好但不如 OpenClaw 灵活
- 有意思的是：OpenClaw 可以控制任何浏览器的标签页，Claude 只能控制自己的 session
