## Question 8
在技能设计铁律中，“Don't State the Obvious（不要陈述显而易见的事实）”意味着什么？

- [x] 不要在提示词中包含基本的编程语法
- [ ] 不要给 Skill 起太简单的名字
- [ ] 不要告诉 Claude 这个 Skill 是用来做什么的
- [ ] 禁止在说明中包含任何示例代码

**Hint:** Claude 已经读过互联网上的大部分公共文档，它不需要你教它基本的 HTML。
