## 🔵 superset — 多 Agent 终端

**GitHub**: https://github.com/superset-sh/superset
**Stars**: 2,054 ⭐ | 169 Forks
**License**: ELv2（源码可用，商用有限制）
**平台**: macOS（Windows/Linux 未测试）

### 核心价值
**同时运行 10+ coding agents，每个独立 git worktree**

### 主要功能

| 功能 | 描述 |
|------|------|
| **并行执行** | 同时运行 10+ coding agents |
| **Worktree 隔离** | 每个 agent 独立分支 + 工作目录 |
| **Agent 监控** | 统一监控，需要时通知 |
| **内置 Diff Viewer** | 不离开 App 就能审查/编辑代码 |
| **通用兼容** | 支持所有 CLI agent |

### 支持的 Agent
- ✅ Claude Code
- ✅ OpenAI Codex CLI
- ✅ Cursor Agent
- ✅ Gemini CLI
- ✅ GitHub Copilot
- ✅ OpenCode
- ✅ **任何 CLI agent**

### 技术栈
Electron + React + TailwindCSS + Bun + Turborepo + Drizzle ORM + Neon + tRPC

### 我的看法
- **解决痛点**：目前跑 Claude Code 只能一个一个来，这个让并行成为可能
- **git worktree 隔离** 是正确的架构选择
- **可能影响 OpenClaw**：OpenClaw 的 subagents 机制和这个理念类似，但 superset 更专注于终端 + agent 编排

## 🟣 Opaal — Claude Code 多 Agent 可视化设计器

**来源**: @aisignals_dev 推特（官网 404，刚发布）
**定位**: Visual designer for multi-agent Claude Code workflows

### 核心功能
1. **可视化设计** - 拖拽 agents，设计多 agent 协作流程
2. **导出 CLAUDE.md** - 把设计转成 Claude Code 配置
3. **导出 .opaal** - 保存设计文件

### 我的看法
- **填补空白**：Claude Code 的 multi-agent 配置需要手写，Opaal 提供可视化方式
- **和 superset 互补**：
  - superset = 运行多个 agent（执行层）
  - Opaal = 设计多个 agent 协作（设计层）
- **可能的方向**：先用 Opaal 设计 → 导出 CLAUDE.md → 用 superset 运行
