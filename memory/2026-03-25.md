#### 3. Payment Enabled Agent（经济独立的关键）

**代码示例**：
```python
from agentstr.agents.agentstr import AgentstrAgent
import asyncio
import os

# 检查环境变量
if os.getenv("NWC_CONN_STR") is None:
    raise ValueError("NWC_CONN_STR environment variable is not set")

async def main():
    agent = AgentstrAgent(
        name="PaymentEnabledAgent",
        description="A simple Agentstr Agent with payment processing",
        satoshis=10,  # 10 sats per message
    )
    await agent.start()

if __name__ == "__main__":
    asyncio.run(main())
```

**关键机制**：
- **NWC_CONN_STR**：Nostr Wallet Connect connection string（从 Alby 获取）
- **satoshis 参数**：每条消息收费多少 sats（1 sat = 0.00000001 BTC ≈ $0.000003）
- **自动支付处理**：agent 生成 lightning invoice，用户支付后才回复

**成本计算**（示例）：
- 10 sats/message ≈ $0.00003/message
- 100 sats/message ≈ $0.0003/message
- 1000 sats/message ≈ $0.003/message

如果每天 100 条消息，100 sats/message：
- 日收入：100 × 100 × $0.000003 = $0.03
- 月收入：$0.03 × 30 = $0.9
- **还不够支付 Neo-cloud 成本**（$0.99-$2.01/小时）

**但如果提供高价值服务**（1000 sats/message × 100 条）：
- 日收入：$0.3
- 月收入：$9
- **可以支付 4.5-9 小时的 Neo-cloud 成本**（足够间歇性使用）
