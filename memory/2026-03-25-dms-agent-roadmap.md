# DMS Agent 升级路线图（2026-03-25）

> **目标**：将 DMS AI Agent 升级为智能运维助手，支持知识库检索、智能推理、安全执行

---

## 技术选型（已确定）

| 组件 | 选择 | 原因 |
|------|------|------|
| **LLM** | ZhipuAI GLM-4.7 | 国产、稳定、Function Calling 支持 |
| **SDK** | ZhipuAI Native SDK (zai-sdk) | 性能最好，无封装损耗 |
| **RAG 框架** | LangChain4j | Java 原生，生态成熟 |
| **向量数据库** | pgvector | PostgreSQL 插件，无需额外部署 |
| **Embedding 模型** | AllMiniLmL6V2 | 本地运行，不需要 API |
