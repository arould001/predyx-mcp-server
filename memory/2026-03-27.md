### 核心发现

#### 1. ClawHub lnget Skill 详细文档 ⭐⭐⭐⭐⭐

**来源**：https://clawhub.ai/roasbeef/lnget

**安全状态**：
- VirusTotal: Suspicious（⚠️）
- OpenClaw: Benign（中等置信度）
- **原因**：可以执行真实微支付，会访问本地钱包凭证
- **建议**：在使用前检查配置和限制

#### 2. 核心功能

**自动 L402 支付流程**：
```
1. 检测 HTTP 402 + L402 challenge
2. 解析 WWW-Authenticate header（macaroon + invoice）
3. 检查 invoice 金额 ≤ --max-cost
4. 存储待定 token（crash recovery）
5. 通过 Lightning backend 支付 invoice
6. 存储已支付 token（含 preimage）
7. 使用 Authorization header 重试请求
```

**Token 缓存机制**：
- 缓存位置：`~/.lnget/tokens/<domain>/token.json`
- 后续请求自动重用 token，无需重复支付

#### 3. 关键命令

**基础使用**：
```bash
# 初始化配置
lnget config init

# 获取 L402-protected 资源
lnget --max-cost 1000 https://api.example.com/paid-data

# 预览但不支付（查看 402 challenge）
lnget --no-pay https://api.example.com/data.json
```

**Token 管理**：
```bash
# 列出所有缓存的 tokens
lnget tokens list

# 查看特定域名的 token
lnget tokens show api.example.com

# 移除 token（强制重新认证）
lnget tokens remove api.example.com
```

**Lightning 后端管理**：
```bash
# 检查后端连接状态
lnget ln status

# LNC（Lightning Node Connect）pairing
lnget ln lnc pair "your-pairing-phrase"

# Neutrino（嵌入式钱包）初始化
lnget ln neutrino init
```

#### 4. 配置文件详解

**位置**：`~/.lnget/config.yaml`

**关键配置**：
```yaml
l402:
  max_cost_sats: 1000      # 最大自动支付金额（sats）
  max_fee_sats: 10         # 最大路由费用
  payment_timeout: 60s     # 支付超时
  auto_pay: true           # 启用自动支付

ln:
  mode: lnd                # 后端模式：lnd / lnc / neutrino
  lnd:
    host: localhost:10009
    tls_cert: ~/.lnd/tls.cert
    macaroon: ~/.lnd/data/chain/bitcoin/mainnet/admin.macaroon
```

**环境变量覆盖**：
```bash
export LNGET_L402_MAX_COST_SATS=5000
export LNGET_LN_MODE=lnc
```

#### 5. 三种 Lightning 后端

| 后端 | 适用场景 | 配置方式 |
|------|---------|---------|
| **lnd** | 本地 Lightning 节点 | `tls_cert` + `macaroon` |
| **LNC** | 远程节点连接 | pairing phrase |
| **Neutrino** | 测试/开发 | 嵌入式钱包 |

**LNC 优势**：
- 不需要本地运行 lnd
- 通过 pairing phrase 连接远程节点
- 支持临时 session（`--ephemeral`）

**Neutrino 优势**：
- 零配置
- 嵌入式钱包，适合测试
- 命令：`lnget ln neutrino init` → `lnget ln neutrino fund`

#### 6. Agent 集成模式

**预算感知获取**：
```bash
# 先检查成本
result=$(lnget --no-pay --json https://api.example.com/data.json)
cost=$(echo "$result" | jq -r '.invoice_amount_sat // 0')

# 检查预算
if [ "$cost" -le "$BUDGET" ]; then
  lnget --max-cost "$BUDGET" -q https://api.example.com/data.json
fi
```

**JSON 输出解析**：
```bash
# 提取响应 body
lnget --json -q https://api.example.com/data.json | jq '.body'

# 检查是否需要支付
lnget --json https://api.example.com/data.json | jq '.l402_paid'
```

#### 7. Exit Codes（错误处理）

| 代码 | 含义 |
|------|------|
| 0 | 成功 |
| 1 | 通用错误 |
| 2 | 支付超过 max cost |
| 3 | 支付失败 |
| 4 | 网络/连接错误 |

**在 Agent 中的使用**：

    print("支付金额超过预算")
