### 1. pmxt - 统一 API（CCXT for prediction markets）

**GitHub**: https://github.com/pmxt-dev/pmxt（1.1k stars）

**核心概念**：
- **Event**：大主题（"谁会被提名为美联储主席？"）
- **Market**：具体可交易问题（"会提名 Kevin Warsh 吗？"）
- **Outcome**：实际购买的份额（"Yes" 或 "No"）

**学到了什么**：
- 预测市场的数据结构（Event → Market → Outcome）
- 统一 API 的价值（一个接口访问多个交易所）
- 交易需要 EIP-712 签名

### 2. 套利机器人（5 分钟市场）

**GitHub**: https://github.com/sssorryMaker/polymarket-arbitrage-bot（370 stars）

**工作流**：
1. 每秒监控订单簿
2. 计算剩余秒数（距离市场关闭）
3. 评估价格 + 时间条件
4. 自动下单

**学到了什么**：
- 套利不一定是跨市场价差，也可以是**时间窗口**内的波动
- 需要精确的入场条件（价格 + 时间）
- 高频交易需要低延迟（WebSocket > Polling）
- 高风险策略，需要测试

### 3. LMSR - 预测市场定价机制

**LMSR（Logarithmic Market Scoring Rule）** 是预测市场的核心算法。

**核心公式**：
```
C(q) = b * ln(Σ e^(qi/b))
```

**变量解释**：
- **C(q)**：总成本（做市商的当前成本）
- **b**：流动性参数（控制市场深度）
- **qi**：第 i 个结果的已发行股份数量

**关键特性**：
1. 成本函数决定价格
2. 流动性参数（b）控制市场深度
3. 连续流动性（AMM 总是作为交易对手方）
4. 有界损失（做市商的最大损失可预测）
5. 概率解释（价格 = 概率，总和为 1）

**学到了什么**：
- 预测市场不是传统订单簿，而是 AMM
- 价格由数学公式决定，不是买卖双方匹配
- 流动性参数（b）是关键

### 4. Kelly 准则 - 仓位大小控制

**Wikipedia**: https://en.wikipedia.org/wiki/Kelly_criterion

**核心公式（赌博）**：
```
f* = (p - q) / b = p - (1 - p) / b
```

**变量解释**：
- **f*** = 最佳下注比例（占总资金的百分比）
- **p** = 获胜概率
- **q** = 失败概率（1 - p）
- **b** = 赔率（盈利 / 下注金额）

**示例**：
- 获胜概率 p = 0.6（60%）
- 赔率 b = 1（1:1 赔率）
- **f* = (0.6 - 0.4) / 1 = 0.2**（下注 20%）

**关键洞察**：
1. **最大化长期增长率**，不是单次收益
2. **满仓 Kelly 风险很高**，实际使用半仓 Kelly（half-Kelly）降低波动
3. **没有优势（edge = 0）→ 不下注**
4. **优势为负 → 下注对手方**

**实验结果（行为学）**：
- 给参与者 $25，60% 获胜概率，30 分钟
- **理论最佳**：下注 20%，最终财富 = $10,505
- **实际结果**：28% 破产，平均只有 $91
- **原因**：大多数人下注太多，不遵守 Kelly

**学到了什么**：
- Kelly 准则告诉你**应该下注多少**
- 但大多数人不遵守，导致破产
- 风险控制很重要：半仓 Kelly 更稳定

### 5. MiroFish - 多智能体模拟引擎

**GitHub**: https://github.com/666ghj/MiroFish（39.7k stars）

**核心**：通过多智能体模拟来预测未来。

**工作流程**：
1. **图谱构建**：现实种子提取 + 个体与群体记忆注入 + GraphRAG 构建
2. **环境搭建**：实体关系抽取 + 人设生成 + 环境配置 Agent 注入仿真参数
3. **开始模拟**：双平台并行模拟 + 自动解析预测需求 + 动态更新时序记忆
4. **报告生成**：ReportAgent 拥有丰富的工具集与模拟后环境进行深度交互
5. **深度互动**：与模拟世界中的任意一位进行对话 & 与 ReportAgent 进行对话

**技术栈**：
- Python（后端）+ Vue（前端）
- LLM API（支持 OpenAI SDK 格式）
- Zep Cloud（长期记忆）
- GraphRAG

**盛大集团投资 3000 万人民币**

**应用场景**：
- 金融方向推演预测
- 时政要闻推演预测
- 公关测试
- 小说结局推演

**实际案例**：
- 有人用 MiroFish 在 Polymarket 上**净赚 12 万美元**
- 钱包地址：`0x17559efac103ac7f361be37ec0b93888d4c55aac`

**学到了什么**：
- 多智能体模拟可以预测社会行为
- Agent 需要长期记忆（Zep Cloud）
- GraphRAG 用于知识图谱构建
- 可以生成可视化报告和交互界面
