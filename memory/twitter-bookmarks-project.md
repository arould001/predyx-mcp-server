## 敏感内容过滤策略

**自动识别规则：**
- 检测关键词（成人内容相关）
- 检测媒体类型（只有图片/视频没有文字的）
- 检测作者信息（成人内容创作者）

**处理方式：**
- 自动跳过，不记录
- 不写入 Obsidian
- 在日志中标记"已跳过 N 条敏感内容"
