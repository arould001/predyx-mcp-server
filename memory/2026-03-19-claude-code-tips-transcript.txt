KEY TAKEAWAYS:

1. FOUNDATIONS
- Run claude in root directory of project
- Use /init to create initial CLAUDE.md
- Keep CLAUDE.md around 300 lines
- Priority: top to bottom (most important first)

2. KEYBOARD SHORTCUTS
- Shift+Tab: toggle modes (accept edits / plan mode)
- Escape: interrupt
- Double Escape: clear input
- Double Escape on empty: rewind context

3. ESSENTIAL COMMANDS
- /clear - clear context
- /context - see current context
- /compact - force compaction
- /models - switch models
- /resume - recover lost session
- /mcp - manage MCPs
- /help - get help

4. WORKFLOWS
- Always start with plan mode
- Fresh context beats bloated context
- Spend time building good context before execution
- Use git as safety net
- Build validation loops (lint, test, build)

5. POWER USER FEATURES
- Skills: reusable workflows as MD files
- MCPs: external integrations (be careful with token bloat)
- Sub-agents: for parallel work and context isolation
- Hooks: pre/post automation

6. ADVANCED WORKFLOWS
- Multiple claude instances (like playing Starcraft)
- Git worktrees for parallel code edits
- /chrome for browser automation
- Notifications when execution completes

7. KEY PRINCIPLES
- Context is king
- Keep it fresh and relevant
- Give Claude what it needs, nothing more
- Never manually maintain your environment
- Let Claude update its own rules
