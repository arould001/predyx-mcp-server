# Multi-Agent Orchestrator

多 Agent 协作编排器，用于 40 人团队的 Agent-Agile 交付模式。

## 场景

- 40 人团队：产品经理、开发、测试、架构师、运维
- 2-3 天/功能的迭代节奏
- 多个 agents 并行执行任务
- 需要实时监控进度、处理依赖

## 架构

```
┌─────────────────────────────────────────────────────┐
│                   Orchestrator                      │
│  (Python daemon - 状态管理 + 任务分发 + 进度汇总)    │
└──────────────────────┬──────────────────────────────┘
                       │
         ┌─────────────┼─────────────┐
         │             │             │
         ▼             ▼             ▼
    ┌─────────┐   ┌─────────┐   ┌─────────┐
    │ Agent A │   │ Agent B │   │ Agent C │
    │ (PM)    │   │ (Dev)   │   │ (QA)    │
    └─────────┘   └─────────┘   └─────────┘
         │             │             │
         └─────────────┴─────────────┘
                       │
                       ▼
              ┌─────────────────┐
              │  Shared State   │
              │  (JSON file)    │
              └─────────────────┘
```

## 核心设计

1. **Shared State**：所有 agents 读写同一个 JSON 文件
2. **Task Queue**：按优先级和依赖关系分发任务
3. **Progress Report**：实时汇总进度，发送到 Discord
4. **Error Handling**：失败任务自动重试或降级
