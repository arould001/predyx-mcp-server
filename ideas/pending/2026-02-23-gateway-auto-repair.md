# Idea: Gateway 崩溃自动修复

> 来源：B站视频 AI超元域
> 优先级：高
> 创建时间：2026-02-23

---

## 问题

Gateway 可能因插件 bug 异常退出：
- 需要人工介入修复
- 无人值守时无法恢复
- 影响服务可用性

---

## 方案

### 修复流程

```
Gateway崩溃 → systemd on failure
    ↓
读日志 → Claude Code 分析
    ↓
定位问题（JSON语法/插件配置/端口冲突）
    ↓
修复 → 重启 Gateway
    ↓
等待8秒 → 检查运行状态
    ↓
还在 → ✅ 成功
不在 → 重试（最多2次）
    ↓
2次失败 → 通知用户
```

### 需要的配置

1. **systemd 服务配置**：OnFailure 触发修复
2. **修复脚本**：读日志 + 调用 Claude Code
3. **通知机制**：失败时通过聊天软件通知用户

---

## 优点

- **无人值守**自动恢复
- 凌晨崩溃也能自动修复
- 不用担心 Gateway 异常退出
