# KimiClaw - 手机版 OpenClaw

**优先级：** ⭐⭐ 高
**发现时间：** 2026-02-22
**来源：** X @aiwarts
**提出者：** Steven

## 背景

Kimi 上线了 OpenClaw 手机版（KimiClaw），可以关联已有的本地 OpenClaw 实例，保留所有记忆、配置、已安装的 Skill。

## 核心价值

**两种接入方式：**

1. **一键部署（云端）** - 在云端跑新的 OpenClaw，配好 K2.5 Thinking + Kimi Search，40G 云盘
2. **关联已有实例** ⭐ - 关联本地已养好的 OpenClaw，所有记忆和配置完整保留

## 研究方向

- [ ] KimiClaw 具体怎么关联本地实例？
- [ ] 手机上能操作哪些功能？
- [ ] 和本地 OpenClaw 的同步机制是什么？
- [ ] 能否操作手机原生 App？（这是安卓方案的核心问题）
- [ ] 费用和限制

## 和"安卓运行 Claw"的关系

- 如果 KimiClaw 能操作原生 App → 可能就是安卓方案
- 如果只能聊天/跑任务 → 是补充，但不是完整的安卓方案
