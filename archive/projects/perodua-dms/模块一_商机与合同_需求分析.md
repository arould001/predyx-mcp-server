## 1. 模块概述与定位

### 1.1 业务定位

商机与合同模块是整个BZT-IC系统的"**资金入口**"模块，处于业务流程的最上游。它决定了项目的预算天花板，是后续成本核算和效能分析的基础数据来源。

**核心价值链**:
```
销售侧(定钱) → 交付侧(花钱) → 财务侧(收钱)
    ↓              ↓              ↓
商机合同      项目运营/工时    财务结算
```

### 1.2 目标用户

| 用户角色 | 主要职责 | 使用频率 |
|---------|---------|---------|
| **销售人员** | 录入商机、跟进记录、售前工时，发起合同签订 | 高频(每日) |
| **销售经理/总监** | 查看团队销售漏斗、业绩统计、审批合同 | 中频(每周) |
| **交付总监** | 从合同发起项目立项 | 低频(按需) |
| **财务人员** | 维护回款里程碑、跟踪回款进度 | 中频(每周) |

### 1.3 模块价值

1. **销售管理**: 规范销售流程，提高转化率
2. **成本溯源**: 售前工时计入成本，完整追踪投入
3. **回款管控**: 里程碑式回款管理，确保现金流
4. **决策支持**: 漏斗分析和业绩统计，支持管理决策

### 1.4 模块边界

**输入来源**:
- 客户信息（来自CRM或手动录入）
- 用户信息（来自系统配置模块）

**输出对象**:
- 项目信息（传递给项目管理模块）
- 回款数据（传递给财务模块）
- 售前工时（传递给工时模块）

## 2. 核心业务实体设计

### 2.1 商机实体 (Opportunity)

```
商机
├── 基础信息
│   ├── 商机名称          string      必填
│   ├── 客户名称          string      必填
│   ├── 预计金额下限      decimal     必填
│   ├── 预计金额上限      decimal     必填
│   ├── 预计签单日期      date        必填
│   └── 商机来源          enum        必填
│       ├── 推荐
│       ├── 自拓
│       └── 老客户续约
│
├── 状态管理
│   ├── 阶段              enum        必填（可配置）
│   │   ├── 线索
│   │   ├── 初步接触
│   │   ├── 需求分析
│   │   ├── 方案报价
│   │   ├── 谈判
│   │   ├── 签单
│   │   └── 流失
│   ├── 成功概率          decimal(0-100)
│   └── 流失原因          string      （当阶段=流失时）
│
├── 关联信息
│   ├── 联系人列表        Contact[]   一对多
│   ├── 跟进记录          Activity[]  一对多
│   ├── 售前工时          WorkLog[]   一对多
│   └── 附件列表          Attachment[] 一对多
│
├── 财务评估 (新增)
│   ├── 预计收入          decimal     (取预计金额区间中间值)
│   ├── 预计人天          int         (可选)
│   ├── 预计人天单价      decimal     (可选)
│   ├── 预计人力成本      decimal     (预计人天 × 平均人天单价)
│   ├── 预计其他成本      decimal     (差旅、采购等)
│   ├── 预计总成本        decimal     (人力成本 + 其他成本 + 售前成本)
│   ├── 预计毛利          decimal     (预计收入 - 预计总成本)
│   └── 预计毛利率        decimal     (预计毛利 / 预计收入)
│
└── 转合同状态
    ├── 是否已转合同      boolean
    ├── 已转换金额        decimal     (累计已转换为合同的金额)
    ├── 剩余金额          decimal     (预计金额上限 - 已转换金额)
    └── 关联合同列表      Contract[]  一对多（支持部分转换）
```

## 5. 核心功能点分析

### 5.1 商机管理

#### 5.1.1 商机创建与编辑

**功能描述**: 销售人员可以创建新商机或编辑现有商机的信息。

**输入字段**:
- 商机名称（必填）
- 客户名称（必填，支持搜索已有客户）
- 预计金额区间（下限、上限）
- 预计签单日期
- 商机来源
- 成功概率

**业务规则**:
- 商机名称不能为空
- 预计金额下限不能大于上限
- 预计签单日期不能早于今天
- 成功概率与阶段联动（系统可自动建议）

**扩展功能**:
- 支持从模板创建商机
- 支持批量导入商机
- 支持商机克隆

#### 5.1.4 商机合并功能 (新增)

**功能描述**: 当发现重复商机时，支持将多个商机合并为一个。

**使用场景**:
- 销售A和销售B都创建了同一个客户的商机
- 同一客户的不同需求可以合并处理
- 商机信息重复录入需要整理

**合并流程**:
```
1. 在商机列表勾选需要合并的商机（2-5个）
2. 点击"合并商机"按钮
3. 选择主商机（保留的商机）
4. 确认合并内容：
   ├─ 跟进记录：全部合并，按时间排序
   ├─ 联系人：去重后合并
   ├─ 售前工时：全部合并
   ├─ 附件：全部合并
   └─ 预计金额：取最大值
5. 确认后执行合并
6. 被合并的商机标记为"已合并"状态（软删除）
```

**合并规则**:
| 字段 | 合并规则 |
|------|---------|
| 商机名称 | 保留主商机名称 |
| 客户名称 | 必须相同才允许合并 |
| 预计金额 | 取最大值（Max） |
| 预计签单日期 | 取最早日期（Min） |
| 商机阶段 | 取最高阶段 |
| 跟进记录 | 全部保留，按时间排序 |
| 联系人 | 去重后合并 |
| 售前工时 | 累加 |
| 附件 | 全部保留 |

**权限要求**:
- 销售人员：只能合并自己创建的商机
- 销售经理：可以合并团队内任何商机
- 合并操作记录审计日志

#### 5.1.2 跟进记录管理

#### 5.1.3 售前工时填报

**功能描述**: 在商机详情页内嵌周历视图，销售人员可以直接填报售前工时。

**特殊处理**:
- 售前工时自动关联到"公共-售前项目"虚拟池
- 每条工时记录打上对应`商机ID`标签
- 售前成本 = Σ(工时 × 个人费率)

**周历视图功能**:
- 显示当前周的工时统计
- 点击日期可填报当天工时
- 支持快速填报（如：今天4小时）
- 显示历史工时记录

**售前工时管控机制** (新增):

| 管控项 | 规则 | 说明 |
|-------|------|------|
| 单日上限 | 8小时 | 超过需要填写说明 |
| 单商机上限 | 100小时 | 超过需要销售经理审批 |
| 月度汇总 | 自动计算 | 显示在商机详情页 |
| 异常提醒 | 自动触发 | 连续7天无跟进后继续填报需说明 |

**管控流程**:
```
售前工时填报
    │
    ├─→ 正常范围（0-8小时/天，累计<100小时）
    │   └─→ 直接提交，自动计入成本
    │
    ├─→ 超单日上限（>8小时/天）
    │   └─→ 需填写加班说明
    │
    └─→ 超商机上限（累计≥100小时）
        ├─→ 系统自动提交销售经理审批
        ├─→ 审批通过后计入成本
        └─→ 审批驳回则退回修改
```

**售前工时报表** (新增):
- 销售经理可查看团队售前工时汇总
- 按商机、按人员统计
- 显示异常填报记录
- 支持导出Excel审核

**功能描述**: 将商机转换为合同，支持完整转换和部分转换两种模式。

**转换模式**:

| 模式 | 说明 | 适用场景 |
|------|------|---------|
| 完整转换 | 商机100%转为一个合同 | 标准签单流程 |

4. 填写合同信息
5. 配置回款里程碑
6. 保存后发起审批流程

**数据继承**:
- 客户信息自动继承
- 商机阶段自动变为"签单"

**人天合同(TM)单价配置** (新增):

当选择"人天合同"计费类型时，需要配置人天单价：

```
┌─────────────────────────────────────────────────────────────────┐
│ 人天单价配置                                                     │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│ 职级          │ 默认单价(元/天)  │  是否覆盖  │  覆盖金额       │
│ ─────────────────────────────────────────────────────────────── │
│ 架构师        │ 2,000           │  ☐        │                 │
│ 高级工程师    │ 1,500           │  ☐        │                 │
│ 中级工程师    │ 1,000           │  ☑ 是     │  1,200          │
│ 初级工程师    │ 600             │  ☐        │                 │
│ 测试工程师    │ 500             │  ☐        │                 │
│                                                                 │
│ [使用系统默认]  [全部恢复默认]                                     │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

**配置说明**:
- 职级列表来自：系统配置模块 → 基础数据字典
- 默认单价参考：系统费率配置（按职级的标准费率）

**计费方式**:
```
人天合同收入 = Σ(实际人天 × 对应职级单价)

示例：

- 中级工程师: 20人天 × ¥1,000 = ¥20,000
- 测试工程师: 5人天  × ¥500   = ¥2,500
───────────────────────────────────────
总计: ¥37,500
```

**附件预览技术方案** (新增):

| 文件类型 | 预览方式 | 技术方案 | 说明 |
|---------|---------|---------|------|

```
附件上传
    │

    │

        ├─→ 显示"处理中..."
        ├─→ 后台异步转换
        └─→ 完成后通知可预览
```

**安全措施**:
- 预览URL添加过期时间（1小时）
- 添加访问Token验证
- 附件添加水印（预览时显示"xxx预览"）
- 禁止预览页面右键保存

### 8.2 数据权限

**商机数据权限**:
- **创建者**: 完全控制（查看、编辑、删除、转合同）

- **团队成员**: 可查看（销售经理可查看团队所有商机）

- **创建者**: 完全控制

- 回款确认
- 立项操作

审计日志包含：
- 操作时间
- 操作人
- 操作类型
- 操作对象ID

## 11. 非功能性需求

### 11.1 性能要求

| 指标 | 要求 |
|------|------|
| 页面加载时间 | < 2秒 |
| 列表查询响应 | < 1秒 |
| 详情页加载 | < 1.5秒 |
| 并发用户数 | 支持100+ |
| 数据量支持 | 商机10万+，合同5万+ |

### 11.2 安全要求

- 所有接口需要JWT认证
- 敏感数据加密存储（费率信息）
- 审计日志完整记录
- SQL注入防护
- XSS攻击防护

### 11.3 可用性要求

- 系统可用性 > 99.5%
- 数据备份每日自动执行
- 支持数据导出（商机、合同）

### 11.4 兼容性要求

- 支持主流浏览器（Chrome, Firefox, Safari, Edge）
- 响应式设计，支持桌面、平板、手机
- 支持中文界面
