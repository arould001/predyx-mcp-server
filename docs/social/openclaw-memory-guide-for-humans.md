> 写给想用 OpenClaw 但不知道从哪开始的朋友

## 先说个扎心的事实

你有没有遇到过这种情况：

- 和 AI 聊了半天，让它记住你的偏好，结果第二天全忘了
- AI 帮你踩过的坑，下次还会再踩一遍
- 每次都要重复告诉 AI 同样的信息

**这就是 AI 没有"记忆"的问题。**

OpenClaw 默认情况下也是"金鱼记忆"——每次会话都是全新的，重启就归零。但是！我们可以给它装一套"记忆系统"，让它：

✅ 记住你的偏好和习惯  
✅ 从踩过的坑里学习  
✅ 越用越聪明，而不是原地踏步  

今天我就手把手教你，怎么给 OpenClaw 装上这套"大脑"。

## 一、这套记忆系统长什么样？

简单来说，就是几个 Markdown 文件：

```
你的 OpenClaw 目录/
│
├── CORE.md          # 最核心的记忆（影响行为的）
├── MEMORY.md        # 重要的长期记忆
├── memory/          # 每天的对话记录
│   └── 2026-02-23.md
├── rules.md         # 从错误中学到的规则
└── RELATIONSHIPS.md # 你认识的人、做的项目
```

看起来有点复杂？别急，我一个一个解释。

---

## 二、三层记忆——像人脑一样工作

这套系统的核心是**三层记忆**，灵感来自游戏 AI（比如《矮人要塞》）：

```
        核心记忆（CORE.md）
        - 永久改变你性格的事情
        - 比如："做决定前先查证"
             ▲ 反复出现才会晋升
        ─────────────────────
        长期记忆（MEMORY.md）
        - 重要的决策、项目进展
        - 比如："2月23日完成了记忆系统"
             ▲ 定期提炼
        ─────────────────────
        日常日志（memory/*.md）
        - 每天聊了什么
        - 比如："今天讨论了记忆系统设计"
```

**为什么分层？**

因为不是所有事情都值得记住。

- "今天中午吃了啥" → 记在日志里，过段时间就忘
- "发现飞书连接失败是因为系统代理" → 提炼到长期记忆
- "涉及最新信息必须先查证" → 晋升为核心记忆

这样 AI 就不会把"午饭吃了啥"和"重大决策"混在一起了。

---

## 三、最重要的功能：话题记忆

**人和 AI 最大的区别是什么？**

人是在"话题结束"时记住事情的，不是在对话过程中逐条记录。

所以我们的系统也是这样：

1. 你和 AI 聊一个话题
2. 话题结束时，你发一个 `/end`
3. AI 自动总结这个话题，写入记忆

**举个例子**：

```
你：我们来设计一下记忆系统...
AI：好的，我建议用三层架构...
你：我觉得可以加个话题感知...
AI：好主意！...
你：/end

AI：（自动总结并写入记忆）
📝 [话题总结] 今天讨论了记忆系统设计
关键结论：三层架构 + 话题感知 + /end 触发
```

这样 AI 就"记住"了这次讨论，下次不会再问"什么是三层架构"。

## 四、最酷的功能：自动学习防错

这是我最喜欢的功能。

**传统 AI**：踩坑 → 忘记 → 下次再踩  
**我们的 AI**：踩坑 → 生成规则 → 永不再犯

**怎么做？**

每次你纠正 AI 的时候，它会自动生成一条"防错规则"：

```markdown
## 规则 #1：信息回复先查询验证

触发事件：我问 Perodua 有没有电车，AI 凭记忆说没有
错误：实际上 2025.12 已经发布了，AI 的知识有截止日期
防错规则：
- 涉及最新信息 → 必须先联网查询
- 不确定就先查，查完再回答
```

下次你再问类似问题，AI 就会先去查，不会再瞎说了。

**这就是从"记住"到"学会"的进化。**

## 五、怎么搭建？Checklist 来了

照着这个清单做，15 分钟搞定：

- [ ] 在 OpenClaw 目录创建 `CORE.md` —— 写入 AI 的核心认知
- [ ] 创建 `MEMORY.md` —— 初始化长期记忆结构
- [ ] 创建 `memory/` 文件夹 —— 存放日志
- [ ] 创建 `memory/heartbeat-state.json` —— 这个后面解释
- [ ] 创建 `rules.md` —— 防错规则
- [ ] 创建 `RELATIONSHIPS.md` —— 记录人名和项目
- [ ] 和你的 AI 约定结束词（推荐用 `/end`）

**核心文件示例**：

**CORE.md**：
```markdown
# CORE.md - 核心记忆

## 🧠 认知模式

### ⚡ 先查再答
- 规则：涉及最新信息必须先联网验证
- 来源：Perodua 电车事件
```

**MEMORY.md**：
```markdown
# MEMORY.md - 长期记忆

## 关于用户
- 姓名：Steven
- 时区：Asia/Shanghai
- 沟通偏好：友好、专业

## 踩过的坑
> 详见 rules.md
```
