## 目录结构

```
docs/
├── guides/               # 教程指南
├── social/               # 社交媒体内容
├── topics/               # 主题文章
│   ├── memory-system/
│   ├── gateway/
│   └── skills/
├── reference/            # 参考资料
└── drafts/               # 草稿
```

---

## 放置规则

| 子目录 | 用途 | 例子 |
|--------|------|------|
| **guides/** | 教程、指南 | 《记忆系统搭建指南》 |
| **social/** | 社交媒体内容 | 小红书、微博文章 |
| **topics/** | 主题深度文章 | 按技术主题分类 |
| **reference/** | 参考资料 | 规范、配置说明 |
| **drafts/** | 草稿 | 待发布内容 |
